# JP-Vision 图标

`jpVision.png` 是用户提供的原始图片副本，未裁剪或更改图案。原始 SHA-256：`FC6F97C57925763CAF50F36FCEBBF0BEE8CAD9B977089D63236572C483E3E60C`。

`jpVision.ico` 包含 16、20、24、32、40、48、64、128、256 像素的图标帧，用于 Windows EXE、Qt 窗口和 WPF 示例窗口。图标资源嵌入可执行文件与程序集，客户程序不依赖 Downloads 中的原始文件。

更换原始图片后，运行 `scripts/update-icon.ps1`，再重新构建 Studio 和 WpfSample。
