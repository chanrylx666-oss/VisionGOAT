# JP-Vision WPF 编辑器操作（0.7.0）

## 海康 GigE 全局相机（2026-10-20 源码）

先在 MVS 停止取流并断开设备，再从“设备 → 全局相机管理…”或工具栏“相机管理”枚举设备、按 SN 连接、开始预览。管理窗最多每秒刷新约 5 次最新图，实际采集 FPS 独立显示。停流后按设备范围调整曝光、增益和帧率。

将工具栏或外部图像节点的图像源切为“全局相机”，所有 ExternalImage 节点共享同次执行的一张图；F5 等待请求后收到的新帧，超时 5 秒。ROI／模板编辑先点“取图用于教学”固定图像，预览不会覆盖教学图或本次检测结果。关闭相机管理窗不等于停止取流；使用“停止预览／断开”控制，退出编辑器会释放连接。本机只保存源模式和首选 SN，与配方分开，不自动连接。操作、错误、资源与限制见 [全局相机图像源](camera-source.md)。

## Blob 分析

在“检测 → Blob 分析”直接连接图像，在模块内设置二值分割、4／8 邻域连通分析及 ROI，按像素面积、包围框尺寸、网格圆度、宽高比、填充率和有效边界筛选。运行结果提供完整区域表、选中区域的质心与包围框，可订阅给后续参数；绿色标记与干净图像分开。像素面积排除孔洞，像素边界周长包含孔洞，具体含义、范围和操作见 [Blob 分析](blob-analysis.md)。

## 不规则边缘点集与距离集（2026-10-19）

“检测 → 边缘点集”用可旋转搜索带逐站获取真实边缘点，保留弯曲边界，不进行直线或圆拟合。“测量 → 点集到线距离”接入点集和现有直线查找的图像输出，计算每点垂距、投影点、统计和公差；支持同一串联图像携带两者。完整点表和距离表在右侧显示，绿色图示可以隔点绘制而不减少结果。见 [操作与 SDK](edge-points.md)。

## 参数订阅、变量和计算函数（2026-10-19）

点击坐标或参数旁的订阅按钮，选择上游结果、变量或表达式。圆环展开圆心 X/Y 可直接使用圆查找选中圆心；同帧先检测再使用，未找到目标则跳过，裁剪图自动处理原点偏移。通过“编辑 → 变量与计算函数”设置配方全局变量、当前算子局部变量与纯函数，例如 `Shift(cx, global.OffsetX)`。绑定 ROI 锁定整块绘制，解除订阅后可恢复手动调整。完整操作、条件判断、坐标边界和 SDK 见 [参数订阅](parameter-subscriptions.md)。

## 圆环展开（2026-10-19）

在工具箱“图像变换”添加“圆环展开”，连入图像后绘制圆环/扇环，或数值编辑圆心、内外半径及起止角。设定展开宽高、方向和插值后执行，结果为横向角度、纵向半径的矩形图像，可直接继续处理。原图标记不会照搬到展开图；展开图的结果使用独立像素坐标，SDK 提供源图映射。详见 [圆环展开](annular-unwrap.md)。

## 图像直连与模块内 A/B 测量（2026-10-19）

每个模块现统一显示一个“图像与结果”输出口，可直接连接下一个模块的图像输入。检测/测量值与独立绿色标记随图像传递，像素保持干净。圆圆、线线、线圆及几何测量可直接接一张图像，在参数面板选择 A/B，分别绘制和调整各自卡尺 ROI，检测拟合后计算；旧配方双几何输入仍可运行。位置修正可以直接读取匹配图像携带的 Pose 并教学。操作及 SDK 见 [统一图像流程](image-pipeline.md)。以下历史版本中的“全部结果”连法继续兼容。

## 算子精细参数（2026-10-19）

参数现按卡尺采样、边缘提取、拟合与剔除、搜索精度、判定、显示等分组，并显示范围、步长和说明。数字支持 +／−、方向键和直接输入，↺ 恢复单项默认值，支持撤销。新增灰度通道、高斯核宽高／双向 Sigma／边界、五种阈值方式、形态学核形状／独立核高／梯度与顶帽黑帽、卡尺均值／中位数投影及亚像素开关、自动圆平滑和自动直线 Canny 梯度选项。旧配方保留原缺省行为，继续通过 VS F5 调试。详细范围和使用方法见 [算子精细参数](parameter-refinement.md)。

## 圆圆距离、线圆距离和绿色结果（2026-10-16）

当前通过根目录 JPVision.sln 在 VS 中运行源码：选择 Debug / x64，将 JPVision.Studio.Wpf 设为启动项目，生成解决方案后按 F5。SDK 已声明对 JPVision.NativeRuntime 的解决方案依赖，原生核心先构建，再复制到托管输出。本轮及后续更新按源码开发交付，普通 bin／obj 和原生构建产物用于验证；独立程序和发布包仅在明确要求发布时生成。下文 local-debug 路径均为历史快照。

在“测量”工具箱中选择“圆圆距离”或“线圆距离”，将上游“全部结果”接入对应的两个输入。圆圆使用“圆 A／圆 B”，线圆使用“直线／圆”；输入来源、目标索引均在算子参数中调整。旧“两圆中心距”直接扩展为“圆圆距离”，组件 ID 和默认圆心距保持兼容。

“距离方式”默认圆心距离，能够切换为圆周最短间距。两种距离会同时出现在运行结果和输出包中；实测值 value、绿色测距连线及公差判断使用当前选定的方式。圆心与半径来自上游实际拟合结果，测量端点是原图坐标，长度为原图像素 px，尚无毫米标定。

圆圆圆心距为 D；圆周最短间距为 max(D−rA−rB, |rA−rB|−D, 0)。相离时测最近边缘；相交或相切时为 0；一个圆包含另一个圆时测两条圆周的间隙，同心时为半径差。线圆圆心距为圆心到无限直线的垂距 D；圆周最短间距为 max(D−r, 0)。直线穿过圆时，零距端点选在真实交点；同心圆的最近点不唯一，严格同心时固定选原图 +X 方向显示。这里使用圆周及无限直线，不使用实心区域或有限线段端点距离。

图像上显示参与测量的拟合圆／直线、当前测量连线、端点和距离文字。运行结果直接显示当前距离、圆心距离、圆周最短间距、几何关系和测量端点。可启用上下限或名义值／偏差公差，继续支持字段绑定、JSON 导出、保存与重载。缺少目标、索引越界或上游数据不可用时距离为空、判定 Unknown，不复用上一帧结果；相交情况下真实测得的 0 仍是有效结果。

新建算子的结果线、拟合点、圆／圆环、轮廓和图形文字默认 #00FF00。已指定颜色的配方保留其设置，可在“标记颜色”中手动改成 #00FF00；附带示例中的旧默认色已同步为绿色。画布主题和 ROI 编辑状态按原界面风格显示。

示例：打开 samples/recipes/circle-distance.vrecipe 或 line-circle-distance.vrecipe，再打开 samples/images/circular-distance.png；默认分别测约 180 px 圆心距、110 px 圆心到线垂距，可在参数中切换为约 126 px、78 px 的圆周间距。C# 工程统一通过 GetGeometricMeasurement("Distance") 获取，原 GetGeometryMeasurement 仍支持圆圆测量。

## 两个直线查找 → 线线距离（2026-10-16）

此功能最初加入历史快照 artifacts/local-debug/line-distance/JP-Vision.exe，当前使用上述 VS 源码工作流。在“测量”工具箱插入“线线距离”，将两个“直线查找”的“全部结果”分别连接到“直线 A”“直线 B”，两条线各自的 ROI 和卡尺参数独立调整。画布显示 A、B 标签，右侧输入来源也可选择上游结果；一个可见的“全部结果”口保留距离、源直线、判定和标记。已有“几何测量”也可把测量方式切换为“线线距离”。

默认取各输入索引 0，即单条卡尺拟合线。自动找出多条直线时需明确选择索引；推荐各自绘制卡尺搜索带定位指定边。平行角度容差默认 1°，可调 0～10°，使用两线的最小夹角（方向相反仍视为平行）。角度等于容差时允许测量，超限时 valid=false、value=null、判定 Unknown，并提示“两线夹角超出平行角度容差”。

测量定义固定为：**直线 A 的拟合线段中点，到直线 B 的无限延长线的垂直距离**。真正平行时就是两线间距；容差内轻微倾斜时，用这个固定位置避免距离含义不明确。图像显示两条拟合线、垂直连线、两端点及距离文字。此处不测有限线段端点间的间隔；B 的垂足可以在线段投影范围之外。交换 A、B 对严格平行线无影响，轻微倾斜时测量位置会改变。

执行后选择“线线距离”的“运行结果”：直接读取距离、两线夹角、允许角度、测量起点／终点的原图坐标。可启用绝对上下限，或“名义值＋上下偏差”公差；上下边界包含在内，按未四舍五入的值判定。当前长度单位是原图像素 px，尚未接入毫米标定。未找到任意一条线、索引越界、输入不可用时距离为空，不返回旧值或假定为 0；同一直线的真实重合距离可以为 0。

“导出本次结果 JSON”保存当前运行的完整数据。WPF 宿主用 GetGeometricMeasurement("Distance") 读取公开结果；value、lineAngleDegrees 和 distanceSegment 的坐标字段也能作为下游数值参数的绑定来源。SDK 示例见 [集成文档](sdk-integration.md#线线距离本地源码增量)。

可打开 samples/recipes/line-distance.vrecipe，再打开 samples/images/line-distance.png 查看示例：两个独立的 25° 卡尺 ROI 测约 72 px 的间距。构建后的程序目录也包含这组示例。

## 直线查找：卡尺搜索带与拟合直线（2026-10-15）

此功能最初加入 artifacts/local-debug/line-caliper/JP-Vision.exe，也包含在当前 line-distance 版中。选中“直线查找”，点击“绘制直线卡尺搜索带”，从待测直线的起点拖到终点。完成后出现可旋转的长条搜索带，卡尺沿中心线均匀布置；拖动两端控制点调整位置、长度和角度，拖动侧面控制点调整搜索高度，拖动带内或中心控制点平移。红色卡尺窗及箭头在明暗背景上均可辨认。

新建的直线查找默认“卡尺拟合（单直线）”。旧配方未指定查找方式时仍按原有自动找线运行；点击上述绘制按钮会切换为卡尺模式，或在查找方式中手动切换。自动找线的阈值、最小线长和断点间距继续保留，仅在自动模式中显示。

搜索带中心线是采样指引，搜索高度由 ROI 高度统一决定，不再在另一个高度参数中重复设置。卡尺数量、投影宽度（奇数）、边缘强度、极性、第一／最后／最强边缘、剔除点数、最大偏差和最小有效比例均可调整。卡尺沿线段法线方向跨越搜索带，具体方向以箭头为准，可勾选“反转搜索方向”。搜索高度须满足当前 Sigma 的采样要求，参考高度上限为 512 px；位置修正会按实际比例变换窗口。

执行后选中直线查找，在“运行结果”读取起点／终点、中点、长度、角度、归一化直线方程 aX+bY+c=0、RMS 及采样／剔除／保留点数，图像上直接显示拟合线和边缘点。“全部结果”端口继续传递全部数据，旧“几何结果标记”也可显示拟合线。线段端点来自有效点在最终拟合线上的投影范围，不是直接返回 ROI 两端。没有有效边缘时返回空目标并说明原因。

卡尺先用稳健拟合确定异常点，再按剔除数与偏差筛选，保留点最终以最小二乘拟合。搜索带保存为已有旋转矩形 ROI，支持取消、撤销重做、保存重载；经位置修正后的旋转／缩放及原图坐标输出也已验证。高级“沿矩形／多边形指定边”和旧手动指引模式继续保留。

## 有一圈点，目标却为 0／没有圆环（2026-10-15 修复）

圆拟合修复最初加入 artifacts/local-debug/circle-refit/JP-Vision.exe，也包含在当前 line-caliper 版中。旧 circle-annulus／circle-target 目录中的程序仍是历史快照，不能只在旧窗口里重跑；保存配方后使用新版重新加载。

采到边缘点不代表已经拟合成圆。已修复的算法缺陷是：初始圆被少量离群点拉偏后，剔除指定异常点的同时仍用这个旧圆检查最大偏差，可能把大部分正确圆周点也删掉。现在先用固定种子、有限候选的稳健一致性估计确定初始圆，剔除指定的最大偏差点后重新拟合，再检查偏差与最小有效比例；后续每次筛点都会重拟合，最终输出仍由保留点最小二乘拟合得到，不能拿教学 ROI 代替。

圆查找“运行结果”现在始终显示采样、剔除、保留点数。没有圆时增加“未输出圆环的原因”，说明边缘点不足、筛选后有效点不足、点集退化或采样区域不可用，并显示至少需保留点数、指定剔除数和本次最大拟合偏差。拟合成功才输出圆心、半径、直径和结果圆环。屏幕上采样／剔除标记仅是诊断，不是测量结果。

最大拟合偏差按当前原图像素计算，5120 图缩小显示时，看起来只有一点偏离也可能超限。应先让 ROI 圆周靠近正确边缘、按孔内向外设置极性，再调整卡尺搜索高度、剔除点数和最大偏差。需要输出圆环还应开启“输出图形标记”“显示标记”，并将结果圆环带宽设为正值。真正采样不足或无法拟合时仍返回空目标及明确原因。

## 测指定的白色内孔，避免误找小圆（2026-10-15）

指定内孔入口最初加入 artifacts/local-debug/circle-target/JP-Vision.exe，也包含在当前 circle-refit 版中。选中“圆查找”，在参数区前面的“测量目标”点击“绘制内孔圆（亮 → 暗）”，从白色孔的中心拖到内孔边缘。可先放大图像，圆周应靠近需要测量的边缘，不要画在金属外圈或螺丝孔上。

绘制完成后才切换为单圆卡尺拟合，沿参考圆向外查找亮→暗边缘。首次从自动模式切换时设为 64 把卡尺、宽度 5、剔除 4 点，并按教学半径设置初始搜索高度、偏差和结果环带宽；这些均可继续调整。已在卡尺模式时重画保留调好的数量、宽高、剔除点数、偏差等采样参数，但按本入口用途设置亮→暗、最强边缘和完整圆周。其他极性或圆弧测量可在下方参数修改。

点击“执行”，选中圆查找查看最终圆心、半径、直径、RMS、采样／剔除／保留点数及结果环。卡尺模式最多返回一个拟合圆；未找到时不返回教学 ROI 充数。搜索高度决定参考圆周两侧寻找边缘的范围，结果环带宽只影响显示；采不到点时先检查参考圆位置、极性和高度。Esc／切换节点会取消未完成教学，配方不变；完成教学整体可用 Ctrl+Z 撤销，保存后可重载。

自动找圆继续保留，适合枚举多个符合半径范围的候选。随程序的 circles.vrecipe 是三个小圆示例，原图半径限定 35～60 px，预期数量为 3；直接换成 5120 大零件图不会自动改成测中间大孔，可能找到螺丝孔或纹理上的小圆。自动模式现在把半径／直径范围放到参数前面；测单个孔可使用上方绘制入口，并将示例预期数量改为 1，或修改旧数量判定节点。编辑器不会擅自改动业务判定。

## 卡尺拟合结果圆环（2026-10-15）

选中“圆查找”，把“查找方式”设为“卡尺拟合”，设置圆／扇环搜索 ROI、卡尺数量、宽高及“剔除点数”。执行时先采样边缘点，剔除异常点后重新拟合；结果面板直接显示采样、剔除和保留点数，以及最终圆心、半径、直径。

“结果圆环带宽（原图 px，0 仅圆周）”控制拟合结果周围的环带，参数 ID 仍为 outputAnnulusWidth。内半径=max(0,拟合半径−带宽/2)，外半径=拟合半径＋带宽/2；使用剔除后拟合几何。搜索 ROI 保持独立，拟合失败时不会拿 ROI 代替检测结果。修改参数后重新执行。

勾选“显示标记”后可直接选中圆查找查看结果；旧配方连接“几何结果标记”也继承相同圆环宽度。默认 4 px 在 5120 大图缩小到 5% 时仅约 0.2 屏幕像素，两个边界容易重合，可放大查看或增大结果带宽。带宽改变只调整标记，不改变拟合半径和卡尺点集。

本次修复版为 artifacts/local-debug/circle-annulus/JP-Vision.exe，窗口验证截图 caliper-result-annulus.png 位于同一目录。旧的正在运行实例需关闭并使用新版重新打开配方；本次未覆盖或强制关闭该实例。

## 图像与流程

打开 `artifacts/studio-wpf/Release/JP-Vision.exe` 或客户端 Studio 文件夹中的 EXE。默认打开圆查找示例。点击“打开图像”导入 PNG、BMP、JPEG、TIFF；图像文件路径仅用于编辑器调试，WPF 宿主通过 SDK 传入像素。

双击工具箱算子或拖入画布。从右侧输出端口拖到左侧相同类型的输入端口；端口支持 Image、Mask、Contours、Features、Measurement、Int、Bool、Overlay。输入只接一个输出，禁止循环和类型不符。右键输入端口断开，右键节点或 Delete 删除，拖动节点改变布局；中键平移，滚轮缩放，“适应窗口”显示全图。Ctrl+Z / Ctrl+Y 撤销重做。

当前源码中圆／直线查找、卡尺、区域分析、模板匹配、快速匹配和快速定位仅显示一个“全部结果”端口（Result）。它包含完整目标列表、测量与诊断、数量、找到目标、数量判定和图形标记。连接到旧类型输入时，编辑器自动选择匹配字段；Bool 输入会弹出“找到目标”与“数量判定”选项。旧连线仍从这个端口显示，无须重画。

工具箱不再列出已内置的矩形 ROI、圆卡尺、几何目标计数、几何结果标记、数量判定、目标计数；在检测模块参数页直接设置 ROI、卡尺和数量范围。独立的轮廓标记仍保留，用于绘制完整轮廓线。隐藏组件仍可加载和执行旧配方。

点击“执行”或 F5，随后选中节点查看实际输出图像与右侧“运行结果”。例如 外部图像 → 灰度转换 → 二值化，选中二值化后会显示掩膜及前景像素数。轮廓节点可直接显示轮廓，几何模块显示图形标记；计数和判定节点直接显示数值／布尔。无需额外结果节点。默认保留所有中间结果；关闭“保留中间结果”时仍保留本次选中节点的完整结果，其余图像需重新运行才能查看。

旧公开输出引用已删除节点时，编辑器提示并使用当前流程执行快照，保存时修复接口。正式 SDK 加载仍严格校验。参数、图像或流程变动会清除旧数值与标记；错误或取消不会显示为检测通过。

## 模块 ROI 与卡尺

长条图的直线卡尺数量已扩展至 32768，结果面板提供采样／剔除／保留计数及真实像素偏差。绿色采样点出现但没有拟合线时，按 [直线卡尺密度与诊断](line-caliper-density.md) 检查容差和最低点数。

ROI 可以贴边或部分超出当前输入图，普通图像处理只使用有效交集，卡尺保留原几何并跳过无效采样。完全无有效区域时返回不可用，不退回全图。圆环展开后的 ROI 使用展开图坐标；高分辨率图像范围与采样限制见 [ROI 边界说明](roi-bounds.md)。

选择支持 ROI 的模块，右侧“检测 ROI”选择矩形、圆形、多边形并点击“绘制／重画”。矩形拖拽绘制，圆形从圆心拖到半径位置；多边形逐点单击，双击或 Enter 完成，Esc 取消。点击“调整”后可拖动区域、矩形角点、圆心／半径控制点及多边形顶点。矩形和圆形还可输入坐标和尺寸，点“全图”清除限制。

ROI 使用当前模块的**输入图局部坐标**，结果自动累加图像 origin，返回原图坐标。编辑 ROI 时显示上游实际输入；执行后默认显示输出图及结果标记，避免把处理结果又覆盖为输入图。

圆查找的“查找方式”选“卡尺拟合”后，可调整卡尺数量、投影宽度、搜索高度、剔除点数、极性、阈值、平滑、拟合偏差、最小有效比例、指引圆半径与圆弧角度。ROI 编辑图上显示每个卡尺窗。圆／直线卡尺输出采样、保留、剔除和未找到点数、RMS 拟合误差及边缘点；圆测量包含圆心、半径、直径、面积、周长。空目标的 selected 为 null，不返回假零坐标。

## 卡尺跟随 ROI 边界（0.7.2）

圆查找先将“查找方式”设为“卡尺拟合”，然后选择“卡尺排列 → 跟随 ROI 边界”，绘制圆形 ROI。圆卡尺采用相同方式；圆心、半径直接取 ROI，沿圆周布置窗口，起止角度仍可限制圆弧。移动圆心或半径时预览同步，不再额外输入指引圆半径。

直线卡尺绘制矩形或多边形 ROI。矩形在“矩形参考边”选上、右、下、左；多边形在“多边形参考边”选择第几条边，图像区标有边编号。拖动区域、改变宽高或移动顶点后，窗口随选定边同步更新。箭头朝 ROI 外侧，边缘极性按箭头搜索方向解释；亮物体向暗背景通常选“亮 → 暗”。

跟随模式中 ROI 是参考路径，卡尺窗口跨边线两侧搜索真实边缘；它不作为本模块的硬裁剪边界，上游 ROI 限制仍生效。窗口太靠近图像边缘、上游裁剪范围过小或高度不足时可能采不到点，请查看“未找到边缘”数量。测量来自实际图像拟合，不直接返回 ROI 几何作为检测结果。

卡尺数量、高度、宽度、剔除点数、平滑与极性仍可调。宽度使用奇数选项 1～63；高度至少满足 max(8, 6×Sigma+6) px。新 WPF 卡尺节点默认跟随，旧配方仍保持“手动指引”，需要时手动切换；手动模式继续使用旧指引半径或线角度／长度。

## 大图圆／直线检测

圆查找的自动模式和直线查找默认“大图处理 → 自动缩小工作图”。输入或检测 ROI 超过 4,194,304 像素时，仅缩小霍夫检测用图，画面仍显示原图；圆心、半径、线端点和长度均返回原图像素，参数也按原图像素设置。右侧“运行结果 → 检测分辨率”和日志显示实际工作尺寸及是否降采样。

需检测小目标或做精确测量时，在模块内绘制较小的检测 ROI，并将“大图处理”切换到“原图（配合 ROI）”；原图 ROI 仍不得超过工作图上限。圆查找也可改用卡尺拟合。自动缩小会降低边缘定位分辨率，不代表原图精细拟合。图像导入上限仍为 32Mi 像素／128MiB。

## 快速匹配与快速定位

当前源码支持“外部图像 → 快速匹配 → 圆查找”：将唯一“全部结果”口连接圆查找的图像输入。新节点默认传递“原图＋定位中心”，圆查找“定位基准”默认自动跟随本次匹配中心。模板只覆盖某个局部特征也可以检测模板框之外的圆；目标索引沿用 resultIndex。旧配方继续原裁图／手动 ROI 行为，要启用跟随须切换这两个参数。

圆查找中选择“卡尺拟合”，绘制待测圆 ROI；绘制／拖动后自动保存相对模板中心的 X/Y 偏移。圆 ROI 半径和卡尺数量、宽高、极性、剔除点数仍可调整，物品平移后参考圆与卡尺同步跟随。未绘制时使用“定位搜索半径”；“自动圆范围”恢复这个设置。选择“输入图 ROI”即可使用手动局部坐标。输出实测圆心、半径、直径和圆轮廓，同时提供可调宽度的输出圆环、独立搜索圆环及真实边缘诊断；右侧直接显示，WPF 可读取整个结果包。

搜索 ROI 选择“全图”或点击“全图搜索”即可清除限制，模板模型保持。全图支持导入上限 32 Mi 像素，评分分块处理。后续圆查找按图像模式显示原图或目标图及标记，关闭全部中间结果保留时，当前节点预览仍正常。无匹配／目标索引越界直接输出空结果，清除定位上下文，不检测其他物品。偏移沿原图轴向，旋转／尺度 ROI 变换仍未实现。

将“外部图像”或预处理输出连接到“快速匹配”／“快速定位”。在模块参数页的“内置模板绘制”选形状，点“绘制模板”，在同一图像区画好目标区域后点“学习模板”。模型包含灰度及形状掩膜，右侧显示模板缩略图；可重画、清除、导入模板图／`.vtemplate`、导出模板。模板宽高 4～512 像素，须包含辨识边缘及少量背景，纯色区域会被拒绝。

模板绘制区域与检测 ROI 独立，学习使用当前连接的上游图像，未学习的模块也能先准备输入图。模板、搜索参数、ROI 与绘制布局随配方保存，支持撤销和重载。快速匹配返回多个物品框，快速定位返回评分最高的一个；均直接提供 x/y/width/height、centerX/Y、score、数量、找到与否、数量范围判定和 overlay。

快速模块用于位置变化，angle=0、scale=1。粗搜索倍数可选 0（自动）、1、2、4、8，候选数有上限，随后按原分辨率精查；未找到有效粗候选时进行完整搜索。存在明显旋转或缩放时，使用原“灰度模板匹配”设置角度／尺度范围。没有承诺任意图像和设备上的固定帧率。

## 保存及 WPF 调用

Ctrl+S 保存为 `.vrecipe` 文件夹，含 recipe.json 与 layout.json；“打开配方”选择其中 recipe.json。未指定输出时自动发布末端端口，默认 processing / Unknown，不强制连接 Bool 判断。供 WPF 按固定名称读取时，打开“编辑 → 公开输出与判定”，选择节点和端口，命名公开输出；仅 Bool 可作为检测通过／失败判定。没有任何额外节点要求。

现有绑定参数（例如示例的 ExpectedCount）在参数页“本次运行输入”中填写；WPF 可通过 RunRequest.Inputs 传入。数值框按 Enter 或失焦提交，枚举和开关立即生效。执行状态、数量判定和整个配方的业务判定分开显示。

未完成模板或连接的草稿可以保存，执行会明确报出待完成项。当前编辑器使用内嵌模板；含外部资源清单的配方可继续通过 SDK 加载执行。
