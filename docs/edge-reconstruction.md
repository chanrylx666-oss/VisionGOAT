# 边缘点集的跳点剔除与曲线重建

这项功能用于卡尺独立选边后出现的尖峰、局部错边或缺点。重建值是根据附近可靠边缘估计的轮廓，不代表缺陷区域内实际测得的边界。原始点保留用于检查缺陷、误选及修复效果；处理只使用本次图像，不借用上一帧。

## 使用方法

在“边缘点集”中绘制覆盖目标边缘的搜索带，先确认极性和选边方式。点击“启用曲线修复”，或在“曲线修复”参数组选择处理方式：

- 原始点集：保持现有逐站寻边和缺段显示。
- 剔除跳点：按局部趋势筛除离群点，可平滑保留的点，不补缺段。
- 剔除并补全：先筛除跳点，再从缺段两侧的可靠点估计内部缺失测站。

主要参数：

| 参数 | 默认值 | 含义 |
| --- | ---: | --- |
| 邻域窗口 | 11 站 | 奇数，3～101；按测站数量观察局部趋势。实际长度还取决于采样间距。 |
| 跳点容差 | 5 px | 超出局部趋势的法向偏差；范围 0.01～32768 px。太小可能剔除真实起伏。 |
| 最大补全长度 | 80 px | 两侧锚点之间沿搜索带的跨度上限，范围 0～32768 px。设为 0 不补段。 |
| 平滑曲线 | 开 | 平滑保留点的位置，并保留原始 X/Y 供比较。原始模式不使用此设置。 |

先用稍大于正常边缘抖动的容差，观察原始点和修正点。连续错边较宽时，可增大邻域窗口，使窗口中仍有足够可靠点；窗口内大多数点都选错时，单靠邻域无法判断真实轮廓，应调整搜索带、极性或选边方式。

## 算法与边界

在搜索带的切向位置／法向位移平面内做局部去趋势的稳健筛选，避免直接比较图像 Y 坐标而误伤倾斜或旋转边缘。缺段使用形状保持的分段三次 Hermite 插值；这种插值的斜率构造参考 [SciPy 的 PCHIP 算法说明](https://docs.scipy.org/doc/scipy/reference/generated/scipy.interpolate.PchipInterpolator.html)，C++ 实现不依赖 Python 或 SciPy。

可选平滑使用距离加权的局部线性回归，并通过 Huber 残差降权降低异常点影响。每个窗口分别估计中心位置，连续窗口形成柔顺曲线；只有左右均有实测支持的点才做平滑。这样可抑制交替锯齿，而不仅是把中值窗口的抖动相位翻转。

只补两侧锚点之间且长度未超限的内部测站。端点外侧不外推，图像／有效掩膜以外不补，整张图无边缘时不生成轮廓。全部采样和输出继续遵守测站及工作量上限。

最低有效点比例根据剔除后仍有实测支持的点计算。补全点不会把覆盖不足的结果变成可靠测量；结果面板分别显示原始、保留实测、剔除和补全数量。

## 后续点到线测量

用户选择的默认方式为“实测合格原始点”：排除补全点，且对经过平滑的保留点使用其原始 X/Y。这样平滑曲线不会悄悄改变实测距离。

选择“修正／补全点集”后，才使用修正后的 X/Y，并允许补全点参与距离统计。每条距离保留点来源及调整标记。判断真实缺陷时，应同时查看原始点和修正差异，不能仅以补全后的平滑程度判定缺陷消失。

## SDK 数据

点集输出的 `points` 是当前模式的最终点，`rawPoints` 保留原始检测点。点上的 `origin` 区分 `measured`／`interpolated`，`adjusted` 表示有实测支持但坐标经过平滑，`rawX/rawY` 保留原始坐标。补全点没有实测梯度，`gradient` 为 0。

点集增加 `rawCount`、`measuredCount`、`rejectedCount`、`interpolatedCount` 和 `observedCoverage`。`count/coverage` 描述输出点集，可靠性仍取决于实测覆盖；原图与圆环展开图继续使用各自的坐标平面。

点到线算子使用 `pointSource=measuredOnly`（默认）或 `all`。旧配方默认继续输出原始点集，旧结果缺少新来源字段时按实测点解释。
