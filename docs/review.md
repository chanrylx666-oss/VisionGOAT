# 交付审查

## 当前源码：模板中心定位与圆环

快速匹配的定位点随真实 Image 一起传递，检测器不将 JSON 当像素。source 模式使用匹配前的实际处理图，target 模式保持旧固定裁图；已有有效掩膜和原点不丢失。FindCircles 对每次有效匹配计算原图参考圆，拟合仍来自真实边缘；未命中及越界索引清空定位，不复用上一帧。圆中心、直径、circle 与 outputAnnulus 为增量输出，搜索 annulus 单独诊断，输出带宽不伪装为第二条材料边缘。

独立审查发现并修复了首次绘制形状与准备后面板不同步、运行负中心写回静态 ROI、边界圆拖动跳位、强制边界卡尺却显示无效指引参数、原图视图提前返回导致缓存复用，以及非编辑状态改 ROI 数字把局部输入显示成原图的问题。原生默认保持 target / image，editorDefault 仅用于新节点。SDK 可空字段兼容旧 Runtime，当前 WPF 控件新增完整圆环绘制。

最终验证 316 个 managed 检查、2 个原生检查、13 个 WPF 流程通过；详见 verification.md。只构建本地 Debug，旋转／缩放下的完整位姿变换和多目标循环仍不属于当前实现。

## 架构边界

0.2.0 的组件注册表同时提供目录描述、算法回调和特殊校验，原有 11 个算法保持端口和行为契约；单文件 MedianBlur 示例实际执行去噪并保持 ROI。新增 Features 为类型化 C++ 圆/线/区域记录，统一序列化和标记，C ABI 保持 1。Hough 像素和结果数量有上限，区域退化轮廓不返回 NaN；失败任务保持 Unknown，SDK 几何读取方法拒绝失败任务和错误的非空特征类型。

Qt/WPF 几何一致性检查按字段比较数值，修正了 JSON 数字文本表示差异引起的误报；改变线段长度的反例确认比较器仍能检测实质差异。

0.3.0 的界面布局、样式/图标、节点绘制、直方图和日志分开实现。常用图标缓存，节点重绘不重复生成位图；直方图最多采样约一百万像素，日志保留最多 2000 块。界面中的参数仍由同一原生目录生成，不复制算法定义。ROI 通过可撤销的图操作插入 CropRect，保持既有配方格式和原图几何坐标；WPF 不依赖 Qt，C ABI 仍为 1。

Runtime 保持 Qt-free；QtNodes 编辑不驱动正式执行。MSVC 与 MinGW 通过 C ABI 交互，内存由分配方释放；SDK 通过 SafeHandle、每任务取消对象与原生接受时保活处理释放和取消。相机、PLC、运动与 MES 不在本次执行范围。

签发私钥经 DPAPI 和账户 ACL 保护，留在工作区外；客户程序固定公钥，不接受 isLicensed 或伪造 machineId。客户端、NuGet、复现包不携带签发秘密或机器许可证。

## 0.7.1 大图检测修复审查

原报错来自 FindCircles／FindLines 的 4Mi 像素霍夫输入上限，图像导入本身支持 32Mi 像素。修复保留工作图资源上限，以默认 adaptive 模式缩小检测图，并同步转换像素参数与返回几何；原图和预览仍保持输入尺寸。逆变换使用像素中心关系，累加模块裁剪原点及外部 origin；多边形 ROI 保留有效掩膜，并在原图空间筛除 ROI 外几何。明确 original 模式先检查上限，再进行灰度转换，避免失败路径先分配大图。

测量增加独立 detection 信息，避免与 caliper 采样诊断混淆；SDK 可读取工作分辨率，已有端口及 C ABI 1 不变。编辑器解析错误对象并标注算子名称／ID，给出中文 ROI／自适应处理建议。失败仍清空公开结果、保持 Unknown；授权检查未改变。

回归覆盖 5120 图像的 Gray/BGR、非紧密 stride、原图 origin、长线段、多边形掩膜及裁剪偏移、原图模式拒绝／小 ROI 成功、空图与错误显示；窗口流程从真实 PNG 解码导入，执行后核验坐标、原尺寸、标记及保存重载。降采样是有损工作分辨率转换，未实现原图精细回拟合，不宣称亚像素测量精度或小目标必能检测；精密场景须用较小原图 ROI 或卡尺。没有发现阻止交付的问题。
