# JP-Vision 开发计划

依据：工作区 VISION_APP_GENERATION_PROMPT.md v2。最新用户要求覆盖临时产品名，正式名称为 JP-Vision。

指定用户的含义已确认：仅允许开发者签发许可证的客户，不新增登录。永久离线许可证绑定电脑，同时保护 Qt 编辑器、C# SDK 和直接 C ABI 执行。签发私钥留在开发者 Windows 账户保护的外部目录。

环境：Qt 6.12.0 MinGW x64，MSVC 14.51 / Visual Studio 2026，.NET SDK 10.0.401，现有 OpenCV 5.0.0 MSVC 分发包。SDK 的原始 OpenCV CMake 导出引用了不存在的旧安装布局，项目使用自己的 imported target 指向真实头文件/库/DLL，不修改用户 SDK。
