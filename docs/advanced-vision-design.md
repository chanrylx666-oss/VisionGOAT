# 0.4.0 模块 ROI、卡尺与模板匹配

目的：模块内部像 Vision Master 一样定义与编辑检测范围；原生执行、Qt 编辑和 WPF 使用同一配方。

每个 Image/Mask 输入模块（保留旧 CropRect）增加可选 roi 参数：none、rectangle（x/y/width/height）、circle（cx/cy/radius）、polygon（3–64 个点）。坐标为上游图像的局部像素坐标；结果继续使用原图坐标。ROI 属于单个节点，不改写共享输入，也不影响平行分支。原生用包围框加有效像素掩膜处理非矩形区域，避免仅用包围框造成范围泄漏。旧配方默认全图，旧 CropRect 继续可运行。

直线卡尺和圆卡尺沿指引分布小测量窗，平均投影、平滑、指定极性的梯度边缘与峰值插值，再拟合直线/圆。参数含数量、搜索长度、投影宽度、阈值、平滑、边缘极性、选择方式和拟合偏差。输出像素几何、边缘点与拟合误差，图像显示测量窗和结果。圆卡尺以模块 ROI 的中心和可调半径布置。

TemplateMatch 从当前图像的教学 ROI 学习或导入模板。Gray8 像素和有效掩膜内嵌配方，最大 512×512，不依赖原模板路径。使用 OpenCV 相关运算计算带掩膜、去均值的归一化相关分数；搜索角度/尺度、分数阈值、最大数量和重叠抑制可调。候选的有效模板像素必须处于搜索 ROI 内。输出中心、角度、尺度、分数和四角，SDK 提供 GetMatches；CountFeatures 和 BuildFeatureOverlay 可直接连接。常量模板拒绝学习，未学习模块允许保存草稿，运行前明确报错。

Qt 参数区增加 ROI 形状/几何编辑、图像编辑和模板教学入口。矩形支持八柄编辑，圆支持移动/半径调整，多边形通过点击添加顶点、双击/Enter 完成、顶点拖动和整体移动；Esc 取消当前未完成操作。操作可撤销、保存、重载；检测修改后清除旧结果。

验证依次覆盖原生 ROI 隔离与几何坐标、已知边缘/圆的卡尺数值、平移/旋转/多目标模板和无目标负例，再检查实际 Qt 编辑、保存/WPF 重放、旧配方和授权拦截。沿用现有永久离线机器授权，不新增登录或免授权入口。
