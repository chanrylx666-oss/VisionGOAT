# 长条图的直线卡尺与拟合诊断

直线查找的“卡尺拟合”与直线卡尺支持 4～32768 个采样窗口，缺省仍为 24。内置 A/B 测量中的直线对象使用相同范围。圆对象继续使用 4～256 个窗口。

对于 10918 px 长的搜索带，256 个窗口的站间隔约为 42.6 px，1024 个约为 10.7 px，2048 个约为 5.3 px。可先设 1024 或 2048，再按纹理、局部缺损和运行耗时调整。窗口切向宽度控制投影平均范围，搜索带高度控制沿法向找边的范围，二者与数量分别设置。

采到一圈／一排绿色点不表示拟合成功。结果图也会显示被剔除的采样点；满足有效点数量和偏差限制后，才会输出实际拟合直线。直线查找使用同一条无限直线解释这些点，真实起伏、选到了不同边缘或局部纹理都可能使残差过大。

运行结果显示请求窗口数、可用图像采样数、找到边缘数、缺失数、剔除数、保留数，以及最低需要保留的点数。还会显示初始点集拟合的最大垂直偏差／RMS、保留点候选的最大偏差／RMS，以及拟合次数。距离单位是当前输入图坐标平面的像素，缩小显示不会缩小这些数值；圆环展开后的偏差属于展开图像素。

推荐按以下顺序调整：

1. 搜索带覆盖要测的同一条边，选对极性与第一／最后／最强边缘。
2. 根据长度提高卡尺数量，检查有效采样与实际采点是否足够。
3. 结合初始偏差与实际精度需求设置“最大拟合偏差”；不要按缩小后的屏幕像素判断。
4. 剔除点数和最小有效比例共同决定最终是否允许拟合。固定剔点后还会按几何偏差筛点，实际剔除数可能更多。

点数不足、偏差筛选后保留数不足、退化或达到拟合迭代上限时，返回明确失败原因及空直线结果，不拿搜索带中线充数。最多细化 128 轮；无候选残差时显示空值，不能用 0 冒充精度。

采样工作量仍限制为 `卡尺数 × (2×ceil(搜索高度/2)+1) × 投影宽度 ≤ 16777216`，适用于手动指引、ROI 中心及边界模式；定位后的实际尺寸也受保护。超过预算时减少数量、高度或投影宽度。预览最多绘制 256 个窗口，实际采样不按预览数量截断。

WPF 宿主可从 `GetResult<VisionLine>(...).Measurement.Caliper` 读取计数与可空诊断字段，如 `ValidSamplingCalipers`、`InitialMaximumDeviation`、`InitialRmsError`、`MaximumRetainedDeviation`、`FinalRmsError`、`EffectiveSamplingSpacing`、`FitIterationLimit`；旧运行库缺少字段时保持 `null`。
