# 不规则边缘点集与点集到线距离

适合长条工件的弯曲、起伏、毛边等不规则边界。用搜索带自动获取真实边缘点，不将它们拟合成圆或直线；随后使用现有“直线查找”的拟合直线作为测量基准。

## 操作

1. 在工具箱 **检测 → 边缘点集** 添加算子，连接外部图像。
2. 在参数面板点“绘制／重画搜索带”，沿待测边缘从起点拖到终点，再调整高度，让搜索带覆盖边缘起伏。可拖动两端旋转、伸缩，拖动侧面改变搜索高度。
3. 调整测站间距、卡尺投影宽度、平滑 Sigma、边缘强度阈值、极性及第一／最后／最强边缘。箭头表示搜边方向；反转方向会同时改变极性与第一／最后的含义。执行后应看到沿不规则边界分布的绿色点。
4. 添加 **直线查找**，在另一条参考边上绘制直线卡尺搜索带，使用卡尺拟合方式输出参考直线。
5. 添加 **测量 → 点集到线距离**。将“边缘点集”的图像输出连接到“点集图像”输入，将“直线查找”的图像输出连接到“参考直线图像”输入。也可以在右侧“输入来源”中选择这两个来源。
6. 执行后在“运行结果”查看距离统计和逐点表格，可导出完整结果 JSON。

出现尖峰、错边或短缺段时，在“边缘点集”中点 **启用曲线修复**，调整邻域窗口、跳点容差和最大补全跨度。原始点、平滑点和补全点可分别追溯；点到线距离默认仍使用实测合格点的原始坐标，明确切换后才包含修正／补全点。详见 [曲线修复与补全](edge-reconstruction.md)。

```text
外部图像 ─→ 边缘点集 ─────→ 点集到线距离：点集图像
        └→ 直线查找 ─────→ 点集到线距离：参考直线图像
```

也支持串联“外部图像 → 直线查找 → 边缘点集 → 点集到线距离”，或先取点再找线。此时同一个图像已经携带点集与直线，测量模块只接“点集图像”即可。

## 点集和距离含义

- 搜索带长度方向布置测站，高度方向搜索边缘。间距为 `sampleSpacing`，站数为 `floor(带长 / 间距) + 1`，最后一站不强行对齐末端。
- 原始模式每站最多保留一个真实边缘点，缺失站保留缺口。修复模式可剔除跳点并补内部短缺段；补全点明确标为估计点，不能提高实测覆盖率。
- 点集包含每个点的 X/Y、测站索引、边缘强度和沿带位置，可供后续模块或 SDK 使用。
- 距离是所选点集到选定无限直线的垂直距离，单位为像素 `px`；默认仅使用实测合格点的原始坐标，可选择修正／补全点集，同时输出点来源、垂足及有符号距离。有符号方向根据规范化参考线方向确定。
- 输出最小、最大、平均、RMS、标准差、极差及极值点。统计项默认选择“最大值”参与公差判定，也可选择最小值、平均值、RMS 或极差。
- “图示每隔 N 点”只减少绿色测距线的绘制数量，不减少输出的点和距离。极值点始终显示。点集预览最多绘制 256 个采样窗口，实际输出仍为完整点集。

## 参数和坐标

默认间距 4 px、投影宽度 5（奇数）、Sigma 1、最小边缘强度 10，保留最强边缘。投影支持均值／中位数，亚像素峰值插值默认开启。可设置最小有效比例，低于该比例时保留实际点供诊断，但不作为有效测量输入。

搜索带高度为 8～32768 px，并需满足平滑窗口要求；最多 32769 个测站、16 Mi 个投影采样工作量。测站数量上限默认仍为 10000，可按需要调大。超限时增加间距或缩小区域，程序不会截断点集冒充完整结果。ROI 数值仍支持上游订阅及变量计算。

### 参数范围与含义

| 参数 | 可调范围 | 缺省值 | 控制的内容 |
| --- | --- | --- | --- |
| 搜索带长度 L | 1～32768 px | 绘制决定 | 沿不规则边缘延伸的长度 |
| 搜索高度 H | 8～32768 px | 新绘制 60 px | 每个测站沿法向寻找边缘的深度 |
| 采样间距 S | 1～32768 px | 4 px | 沿长度方向两个测站之间的间距 |
| 卡尺切向宽度 W | 1～255 px，奇数 | 5 px | 每个测站沿边缘方向参与均值／中值的宽度，与采样间距不同 |
| 法向平滑 Sigma | 0～10 px | 1 px | 平滑灰度投影；0 不平滑，搜索高度须至少为 max(8, 6×Sigma+6) |
| 最低边缘梯度 | 0～255 灰度级/px | 10 | 边缘对比强度；不是距离，0 仍要求真实非零边缘 |
| 最低有效点比例 | 0～1 | 0.5 | 0.5 即 50%，控制点集是否足够完整 |
| 测站数量上限 | 2～32769 个 | 10000 个 | 允许布置的总测站数，并非要求输出这么多个点 |

参数面板显示预计测站数 `N = floor(L/S)+1`、最低需要的有效点数及当前组合是否可执行；预览最多画 256 个窗口，实际采样和输出不因此减少。工作量为 `N × (2×ceil(H/2)+1) × W`，不能超过 16777216。单项都在范围内，组合仍可能超过预算，面板会提示增加间距或减小搜索高度／切向宽度。超限时保留真实预计数量，不再显示容易误解的“0 个测站”。

例如长度 10918 px、间距 1 px 需要 10919 个测站，应把数量上限调到至少 10919；点集到线距离已支持同样的点数上限，计算与完整距离数组不会被截断。

点与参考线均使用其图像坐标平面的绝对像素坐标，裁剪图会计入原点。原图与圆环展开图、两个独立展开分支不能交叉测距。图像像素保持干净，绿色 `#00FF00` 标记单独显示和传递。

没有绘制 ROI、没有足够边缘、参考线缺失或订阅参数不可用时，显示明确原因；距离数组为空、统计为空、判定未知，不取上一帧结果，也不使用 0 代替缺失距离。

## WPF SDK

以下接口位于本次源码 SDK；WPF 宿主可引用 `managed/JPVision.Sdk/JPVision.Sdk.csproj` 或对应的本地构建程序集。原生运行库依赖的放置方式沿用 [SDK 集成](sdk-integration.md)。

以下名称是配方公开输出名；可公开完整结果，也可公开携带结果的图像：

```csharp
VisionEdgePointSet points = result.GetEdgePoints("PointsImage");
VisionPointLineDistances measurement = result.GetPointLineDistances("DistanceImage");
if (measurement.Valid)
{
    foreach (VisionPointLineDistance item in measurement.Distances)
    {
        // item.X/Y：边缘点；ProjectionX/Y：垂足。
        double distance = item.Distance;
        double signedDistance = item.SignedDistance;
    }
    double? maximum = measurement.Maximum;
    double? average = measurement.Mean;
}
```

图像上下文还可通过 `GetImageAttachedOutput<T>(name, "PointSet")` 读取点集。新类型为 `edgePointSet` 和 `pointLineDistances`，不改变既有圆、直线及单点几何测量的结果结构。
