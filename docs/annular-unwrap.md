# 圆环展开

在算法工具箱“图像变换”中添加“圆环展开”（AnnularUnwrap），连接任意图像输入。模块将圆环或扇环采样为矩形图像，保持 Gray8/Bgr24 格式，输出可直接连接二值化、形态学、轮廓及检测/测量模块。

## 操作

1. 选中模块，在算子参数中点击“绘制 / 重画圆环”。从圆心拖到外半径，再调整内圆和角度手柄；Esc 取消。
2. 可直接编辑圆心 X/Y、内外半径、起止角，按 Enter 或离开输入框保存；支持既有撤销、保存和重载。
3. 设置展开宽高及方向，点执行。横向对应角度，纵向对应半径；输出原点为 `(0,0)`。后续裁剪的原点是展开平面中的偏移。

内半径允许 0，外半径必须更大；角度跨度沿用圆环 ROI 的 10～360°，起始角 -360～360°、终止角 -360～720°。0° 向右、90° 向下。允许部分圆环超出图像，超出部分为黑色无效区，后续分割/检测排除它们；全部无效时返回不可用，不回退原图。

## 参数与采样约定

| 参数 | 默认值与行为 |
|---|---|
| 展开宽度 | 0 自动：平均半径 × 角度跨度（弧度），向上取整 |
| 展开高度 | 0 自动：外半径 − 内半径，向上取整且至少 1 |
| 角度展开方向 | 顺时针；逆时针从终止角反向采样同一范围 |
| 半径展开顺序 | 从内圈到外圈；可反转 |
| 采样插值 | 双线性；最近邻适合保持二值图像像素值 |
| ROI 坐标基准 | 输入图像；也可使用已教学的位置修正基准 |

宽为 W 时，顺时针第 x 列的角度为 `startAngle + span*x/W`；逆时针为 `endAngle - span*x/W`。整圆不会重复首尾接缝列。高为 H>1 时，半径包含内外端点；H=1 采平均半径。内到外时第 y 行半径为 `innerRadius + (outerRadius-innerRadius)*y/(H-1)`。

单边最大 32766 像素，输出最多 16 Mi 像素，两张浮点采样表最多 128 MiB。自动尺寸超过限制时请指定更小宽高或减小圆环范围。算法不修改输入像素。

## 坐标与后续处理

展开为非线性变换，输出使用 `coordinateSpace=annularUnwrapped` 和独立的 `coordinatePlane`。原图上的圆线、Overlay、匹配位置和 fixture 不会照搬到展开图；后续检测生成的结果使用展开图像素坐标，并可正常显示独立绿色标记。同一展开分支内可以测量，原图与展开图、两个独立展开模块的几何结果不能直接混合测距。

展开坐标的一个水平像素代表一定角度，一个垂直像素代表一定半径增量；它们受输出宽高影响，不能把展开图像素距离直接当作原图长度或实物毫米。需要源图坐标时使用映射。

## WPF SDK

公开 Image 输出保留 `coordinateMapping`，包括源图坐标空间、圆心、角度/半径起点及步长。图像经过后续处理和裁剪，映射仍保留。

```csharp
using var result = await session.RunAsync(frame);
if (result.Status == ExecutionStatus.Succeeded)
{
    using var expanded = result.GetOutputImage("Unwrapped");
    var map = result.GetAnnularMapping("Unwrapped");
    VisionPoint sourcePoint = map.MapToSource(100, 20);
    // 参数是展开平面的像素坐标，包含下游裁剪原点；返回直接上游源图平面的坐标。
    // 若 map.SourceCoordinateSpace == "original"，返回值就是原图坐标。
}
```

`MapToSource` 拒绝非有限值或超出展开画布的点。重复展开时映射只指向直接上游平面，不能自动跨越多次非线性变换。检测包/测量包的 CoordinateSpace 区分原图和展开图；旧原图配方与 C ABI 保持兼容。

仍在 VS 中以 Debug/x64 生成解决方案并 F5 运行源码，无需发布安装包。
