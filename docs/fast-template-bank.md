# 快速匹配：多模板与尺寸搜索

快速匹配、快速定位现在可在同一算子保存多个模板。每个模板有稳定编号、显示名称、启用开关和自己的灰度／形状掩膜；模板随配方保存，不依赖外部图片路径。编辑器的模板管理业务使用 C#，匹配计算继续调用现有 OpenCV 原生内核。

## 使用方法

1. 将外部图像连接到快速匹配，打开待教学图像。
2. 在算子内绘制物品模板区域，点击学习；要保留当前模板并增加另一个物品，使用“学习为新模板”。可选中列表中的某个模板重新学习、改名、启用或删除。
3. 在“检测 ROI”选择“全图搜索”，在整张当前输入图上寻找。模板绘制区域与检测搜索范围相互独立；需要限定区域时仍可绘制检测 ROI。
4. 工件有尺寸变化时，使用“尺寸浮动 ±10%”，或分别设置最小尺度、最大尺度和尺度步长。例如 `0.9 / 1.1 / 0.05` 搜索教学尺寸的 90%～110%。`1 / 1` 表示固定教学尺寸。
5. 执行后查看选中的模板名称／编号、匹配分数、定位中心 X／Y、尺度及包围框。连接后续算子时，图像和本次选中的定位结果照常传递。

模板库模式会比较所有启用模板、所有请求尺度的候选，输出**分数最高的一条**；分数相同时，优先列表中靠前的模板，再按尺度和图像位置稳定选择。没有达到最低分数的候选时输出空结果，不沿用上次位置。

旧单模板模型和配方仍可直接使用。旧快速匹配的最大目标数量设置继续生效；快速定位始终选择一条。模板库模式按本次需求固定选择全库最佳，最大目标数量不改变这一规则。

## 尺度与算法

尺度是相对教学模板的等比例放大／缩小，范围 `0.5～2`，步长 `0.01～1`。搜索显式包括上下限及范围内的 `1`。它不是修改原图的像素尺寸，也不是降低最低分数。输出框使用实际缩放后的像素宽高，中心仍使用当前输入图坐标平面和原点。

算法沿用归一化灰度相关匹配：矩形有效模板使用 OpenCV `TM_CCOEFF_NORMED`；形状模板使用掩膜内零均值归一化相关。每个尺度对模板灰度做线性插值、对掩膜做最近邻插值；大图先粗搜索，再在原图局部精搜，必要时回退全分辨率。搜索位置分块覆盖边界和块接缝，最后跨模板、尺度比较分数。原图只准备一次灰度数据，模板解码缓存不保存检测位置。

这是灰度模板匹配。等比例尺寸变化适用；明显旋转、局部变形、透视变化或亮面反光仍可能改变分数，需要重新教学或选择其他检测方案。快速模块本次没有加入旋转搜索。

原有圆查找的“跟随匹配中心”继续按其既有规则平移 ROI；需要把半径或尺寸也随尺度改变时，可订阅匹配的 `measurement.selected.scale`，用参数表达式计算，不会隐式改变旧配方的 ROI 尺寸。

## 保存与 SDK

模板库沿用 `model` 参数，旧单模板结构不变；库结构为：

```json
{
  "templates": [
    {
      "id": "part_a",
      "name": "工件 A",
      "enabled": true,
      "model": { "width": 48, "height": 40, "grayBase64": "…" }
    }
  ]
}
```

每库最多 8 个完整模板，编号唯一；名称允许相同，编号用于区分。所有存储的模板均须满足原有尺寸、像素长度、有效掩膜和灰度对比校验，禁用模板也不例外。运行时至少启用一个。启用模板数乘以实际尺度数不得超过 121；缩小步长、增加模板会增加处理时间。每次算子的实际粗搜、精搜和回退搜索块累计最多处理 512 MiPixels；超限明确报错，不输出尚未完成全库比较的结果。模板宽高仍为 4～512 px，缩放后的搜索模板最多 1024 px。

SDK 的 `VisionMatch.TemplateId`、`TemplateName` 表示获胜模板；`Score`、`CenterX`、`CenterY`、`Scale` 保留原有含义。旧单模板结果的两个新增字符串为空。模板名称／编号也可订阅。导入模板会追加到当前模板库；导出保存整个库。
