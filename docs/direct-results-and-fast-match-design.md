# 当前流程结果与快速模板定位（0.7.0）

用户报告：替换示例流程为 外部图像→灰度转换→二值化后，执行报 Output refers to missing node。截图确认公开输出仍引用已删除节点。编辑器需要直接运行当前连线并显示各算子的图像、轮廓、数量、布尔和几何结果。

编辑器的执行快照检查公开接口引用是否仍有效；失效则临时生成当前末端输出的 processing 快照，清空检测判定，并提示公开接口需重新发布。有效接口保留名称／类型／判定。为显示新接上的未公开分支，快照可追加 previewNodes（当前末端节点，不变更公开输出），原生编译把它们及祖先加入执行顺序；该字段受内容摘要保护。原配方和 SDK 的正式公开输出仍严格校验，禁止把不存在的检测结果冒充 Pass。

运行结果增加 nodeOutputs[nodeId][portId]：图像元数据和标量始终有，完整轮廓／几何／标记在 Debug 或选中节点预览时保留。previewNodeId 请求允许关闭 Debug 时仍保留本次选中节点的图像和完整结果。沿用 debugValues/debugOverlays、measurements、256 MiB 调试预算和真实许可证。选中节点后显示其实际输出；只有明确编辑 ROI 时切到输入图。处理完成自动选择末端图像，不再被 ROI 输入预览覆盖。改图／改参清空旧结果。

新增 FastTemplateMatch（快速模板匹配，多目标）和 FastLocate（快速定位，最佳单目标）。用户确认物品主要平移，默认不搜索旋转／缩放。复用原模板编码和掩膜校验，提供灰度归一化相关匹配、自动／可调粗搜索缩小倍数、有限候选、原分辨率精查、评分门限和去重。返回完整位置框、中心、评分、angle=0、scale=1、数量、找到与否、数量判定和图形标记。空匹配输出空列表／空选择，不返回假坐标；含颜色、角度或尺度变化时可用原灰度模板匹配模块另行设置。

快速模块内部含模板绘制区：在同一图像预览中绘制矩形／圆形／多边形模板区域，再确认学习；模板区域与搜索 ROI 分开，不通过新增流程节点实现。可预览、重画、导入、清除模板，支持撤销和保存重载，模型内嵌配方供 WPF 无需 Qt 调用。模板须包含有辨识度的边界和背景，纯色学习被拒绝。

用户已确认将编辑器界面改为 C# WPF，视觉核心保留 C++。新编辑器采用 .NET 10 WPF／x64，独立 Editor.Core 管理流程、接口、撤销和模板编码，使用现有 net8 SDK／C ABI 调用 MSVC OpenCV 核心。Visual Studio 解决方案包含编辑器、原生核心、SDK、示例和测试，默认构建／发布入口切换到 WPF。原 Qt 源码保留作迁移参考。许可证在启动和执行时校验 editor 与 runtime 功能，继续离线、机器绑定、永久授权，不增加登录。

验证按增量：先复现失效输出、选中 ROI 算子被输入图覆盖和新分支不执行，再验证完整结果显示；用真实合成图覆盖模板平移、多目标／最佳目标、掩膜、ROI／原图偏移、空图、错误模型与资源预算；GUI 覆盖模块内模板绘制／学习／重画／保存、算子选择和错误结果清除；VS 实际构建和发布、隔离消费端及授权负例。
