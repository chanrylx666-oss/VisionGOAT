# 高分辨率图像与 ROI 边界

ROI 以当前算子的输入图为准。圆环展开后的长条图有独立的展开坐标平面；后续直线查找、边缘点集应在这张展开图上绘制搜索带，不能沿用原图的圆心坐标。

普通图像处理算子的矩形、旋转矩形、多边形、圆形和圆环 ROI 可以贴边或部分超出输入图。只处理图内的有效交集，保持形状掩膜，裁剪后的原点偏移仍随图像传递。不为图外部分扩充画布，也不改动并行分支的图像。

圆／直线卡尺、边缘点集和双边卡尺保留原先绘制的几何位置及采样方向。越界或来自无效掩膜的采样不参与检测；有效采样和拟合点仍须满足最小有效比例、剔除点数与拟合偏差要求。没有足够有效采样时不生成假圆、假直线或沿用上一帧。

ROI 完全没有覆盖有效像素时，显示 ROI 不可用或有效采样不足，下游判定为未知；不会退回全图检测。需要精确裁出一块固定尺寸图像的独立 `CropRect` 仍要求裁剪矩形完整位于图内。

10918×287 的长条图可在全宽范围内绘制直线卡尺搜索带，轻微旋转或贴边不再因为 ROI 包围框多出一个像素而终止执行。搜索带的长度与搜索高度是不同参数：直线卡尺参考高度仍为 8～512 px，边缘点集搜索高度已扩展为 8～32768 px，且需满足平滑窗口与采样预算要求。边缘点集各项数值范围见 [边缘点集说明](edge-points.md)。

运行库现有单边 32768 px、总像素 32 Mi 的输入图容量，以及 16 Mi 的卡尺采样工作量限制继续生效；圆环展开的源／输出单边上限为 32766 px。遇到采样预算提示时，可减少卡尺数量、增大点集采样间距或缩小搜索高度。
